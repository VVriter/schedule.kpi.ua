# Інтеграція з Google Calendar

## Опис функціональності

Додано можливість експорту розкладу занять до Google Calendar з трьома рівнями деталізації:

### 1. Експорт однієї пари
- **Розташування**: Кнопка "Календар" у кожній карточці пари
- **Функціональність**: Відкриває Google Calendar з формою створення події для конкретної пари
- **Дані**: Назва предмету, час, викладач, аудиторія

### 2. Експорт дня
- **Розташування**: Кнопка "День" у заголовку кожного дня тижня
- **Функціональність**: Відкриває кілька вкладок Google Calendar для всіх пар дня
- **Особливості**: Автоматична затримка між відкриттям вкладок (100мс)

### 3. Експорт тижня
- **Розташування**: Кнопка "Експортувати тиждень до Google Calendar" вгорі розкладу
- **Функціональність**: Відкриває всі події тижня пакетами по 5 для уникнення блокування браузером
- **Особливості**: Затримка 1 секунда між пакетами

## Технічна реалізація

### Нові файли:
- `src/services/googleCalendar.ts` - основна логіка роботи з Google Calendar
- `src/components/GoogleCalendarButton/` - компонент кнопки
- `src/components/WeekExportButton/` - компонент для експорту тижня
- `src/containers/ScheduleHeader/WeekDayWithExport.tsx` - заголовок дня з кнопкою експорту

### Змінені файли:
- `src/containers/ScheduleItem/ScheduleItemBase.tsx` - додано кнопку експорту пари
- `src/containers/ScheduleTable/ScheduleTable.tsx` - додано кнопку експорту тижня

## Особливості використання

1. **Формат часу**: Система автоматично обробляє різні формати часу та має fallback для некоректних даних
2. **Типізація**: Кнопки показуються тільки для студентського розкладу (не для викладачів)
3. **Обробка помилок**: Логування попереджень у консоль при проблемах з форматом даних
4. **UX**: Кнопки стилізовані відповідно до існуючого дизайн-системи проекту

## Стилізація

Використовується існуюча система стилів проекту:
- Компонент `Button` з варіантами `primary`, `secondary`, `tertiary`
- Розміри `sm`, `md`, `lg`
- Кольорова схема з `theme.ts`
- Іконка календаря у SVG форматі

## Браузерна сумісність

Функціональність використовує стандартні веб-API:
- `window.open()` для відкриття нових вкладок
- `URLSearchParams` для формування URL
- `setTimeout()` для затримок між запитами
